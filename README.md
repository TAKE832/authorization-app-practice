## 概要

COACHTECH 教材 Tutorial 10-3「認可機能 ハンズオン演習で作成した成果物です。
（PostPolicyを生成し、投稿者だけが編集・削除・表示可能な機能を持った投稿一覧ページを実装しました。）

## 使用技術

- PHP 8.x
- Laravel 10.x
- Policy / Gate（認可）
- Laravel Fortify（認証）

## 学んだこと

- ポリシーを定義することで、セキュリティや投稿の保守性の高いサイトを作ることができることが分かった。
- Bladeで @can を使って投稿者のみが編集・削除可能なページへのボタンを表示することで、閲覧者側の誤操作の防止や投稿の変更・削除を制限できるのではないかと思った。
- ポリシークラスを生成することで、認可に関わるロジックをまとめることができ、コードの役割分担を行うことができたり、再利用性を高めたりすることができることが分かった。
